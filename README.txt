- style.css / script.js: layout e interações

COMO RODAR NO WINDOWS:
1) Extraia este ZIP.
2) No VS Code, abra a pasta portfolio-fernando-v6.
3) Instale a extensão Live Server (Ritwick Dey), se necessário.
4) Abra index.html com Open with Live Server.
5) Não precisa executar npm install nem configurar banco de dados.
